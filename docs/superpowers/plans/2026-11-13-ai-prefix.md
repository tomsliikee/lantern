# AI prefixes Implementation Plan

> **For agentic workers:** Implemented natively in one session. Steps use checkbox syntax.

**Goal:** `claude:` and `agy:` in the field send the text to that CLI and stream the answer into a card in the panel; Enter asks a follow-up, Esc returns to normal search.

**Architecture:** Pure logic in `extension/lib/ai.js` (tested). A subprocess runner in `extension/sources/ai.js`. A card widget in `extension/views/ask.js`. `views/panel.js` gets an "ask mode" beside normal search.

**Tech Stack:** GJS (`Gio.Subprocess`), St/Clutter, `gjs -m` tests, the headless rig.

**Spec:** `docs/superpowers/specs/2026-11-13-ai-prefix-design.md`. Look: `ai-mode-mockup.html`.

## Global Constraints

- Nothing runs while closed; no timer while idle (the pacing timer exists only while text is waiting to be shown).
- No new dependency. English in code; German strings in `po/de.po`.
- Normal search is untouched when no prefix is typed.
- The stylesheet is generated: edit `tools/stylesheet.template.css`, run `node tools/build-tokens.js`.
- Nothing is committed until Thomas says so.
- Tests: `for t in tests/*.test.js; do gjs -m "$t"; done`; panel: `tools/headless/run.sh <script>`.

## Review Focus

1. CLI not found in the shell's PATH (`~/.local/bin`): the card says so in one sentence. Test: `commandLine` names the program; the runner looks in `~/.local/bin` too.
2. Esc while running: the process is killed, partial text stays, no later event changes the card.
3. Prompt empty after the prefix (`claude:`): Enter does nothing, chip stays.
4. Unclosed code fence while streaming: shown as code, not lost. Test in `splitBlocks`.
5. Malformed or unknown JSON line: ignored. Test in `parseLine`.

### Task 1: lib/ai.js

**Files:** Create `extension/lib/ai.js`, `tests/ai.test.js`.

**Produces:**
- `PROVIDERS: {claude, agy}` each `{id, name, program}`.
- `parsePrefix(text) -> {provider, prompt} | null`: `claude:` / `agy:` at the start, case-insensitive; prompt is the rest with leading spaces removed.
- `commandLine(provider, prompt, session) -> string[]`.
- `parseLine(provider, line) -> {kind: 'session'|'thinking'|'text'|'done'|'error', ...} | null`.
- `splitBlocks(text) -> [{code: boolean, text: string}]`.
- `nextShown(shown, total) -> number`: how many characters are visible after one tick.

- [ ] Tests first: prefix cases (`Claude: hi`, `agy:x`, `claude`, `xclaude: a`, `claude:` gives empty prompt); command lines (claude new and `--resume`, agy new and `--conversation`); `parseLine` on recorded lines of both CLIs (session id, thinking, text delta, done, error result, garbage); `splitBlocks` (plain, fenced, unclosed fence); `nextShown` (never exceeds total, always moves forward by at least 1, catches up on a large backlog).
- [ ] Run, expect FAIL; implement; run, expect PASS.

### Task 2: sources/ai.js

**Files:** Create `extension/sources/ai.js`.

**Produces:** `class AskRunner { constructor({onEvent}); send(provider, prompt); cancel(); reset(); get running(); }`. `onEvent` receives the `parseLine` events plus `{kind: 'error', message}` for a missing program, a non-zero exit without text, or a spawn failure. Keeps the session id between `send` calls until `reset`. Runs in the home folder, finds the program in `PATH` or `~/.local/bin`. After `cancel` or `reset` no event is delivered.

- [ ] Implement with `Gio.SubprocessLauncher` and `Gio.DataInputStream.read_line_async`; `force_exit()` on cancel.
- [ ] Check by hand with a small gjs script against both CLIs.

### Task 3: views/ask.js and styles

**Files:** Create `extension/views/ask.js`, `extension/icons/ms-spark-symbolic.svg`; modify `tools/stylesheet.template.css`, `extension/stylesheet.css` (generated), `extension/views/text.js` (roles `ask-said`, `ask-reply`, `ask-code`), `po/de.po`.

**Produces:** `class AskCard` with `addTurn(said)`, `setThinking(on)`, `append(text)` (paced reveal), `finish()`, `fail(message)`, `clear()`, `get lastReply()`. Chip widget `makeChip()`.

- [ ] Render turns as in the mockup: the question in the serif, the reply in Inter, code blocks on a filled rounded box, pulsing dots while thinking, the calm style for an error.

### Task 4: panel wiring

**Files:** Modify `extension/views/panel.js`.

- [ ] `_changed`: a prefix enters ask mode (chip on, entry holds the prompt, no search). Ask mode ignores text changes.
- [ ] Enter sends (non-empty, not running); Esc cancels a running request, else leaves ask mode, else closes; Up/Down/Tab ignored in ask mode; Ctrl+C copies the last reply.
- [ ] Panel grows when the first turn is sent; the preview column is hidden in ask mode; footer shows `Enter follow-up`, `Esc back to search` and the time.
- [ ] `close()` and `_finishClose()` cancel and reset.
