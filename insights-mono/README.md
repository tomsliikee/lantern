# Insights Mono

The design system of Material Search: black, white and grey, colour only where it means something. Copied on 2026-11-12 from the Claude design system artifact `ExgRm9R1bk2HnyTe3hrLBC` (synced there from Pulse and Horizont on 2026-11-06).

- `tokens.json`: all values; the build (`tools/build-tokens.js`) uses the `light` and `dark` themes only.
- `fonts/`: Geist Serif (serif titles) and Inter (everything else), both under the SIL Open Font License; the licence texts sit beside them.
